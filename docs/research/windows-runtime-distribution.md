# Windows runtime distribution

Publish the Simple STT build of Parakeet CUDA as a ZIP on a versioned GitHub Release in a dedicated repository. Include the build recipe, full upstream notices and a SHA-256 digest. Use the vendor downloads for NVIDIA and Microsoft prerequisites. The five runtime DLLs total about 46 MiB before compression. GitHub documents a 2 GiB limit per release asset and reserves the right to throttle excessive usage. Its Terms require publishers to have the right to post third-party material and comply with its licenses. Hugging Face also requires distribution rights and grants platform users rights through public repositories. GitHub Releases directly supports downloadable software binaries. [GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases), [GitHub Terms §D](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#d-user-generated-content), [GitHub Acceptable Use](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies), [Hugging Face Terms](https://huggingface.co/terms-of-service#-your-content), [Hugging Face storage limits](https://huggingface.co/docs/hub/storage-limits).

## Build and license evidence

- The tested build is Parakeet v0.5.0 C ABI 6, Windows x64, with CUDA 12.8 and MSVC 19.44.35227. Ninja generated `compute_120a` and `sm_120a` code. The local `external/parakeet-runtime/parakeet-windows-cuda/BUILD_INFO.txt` reports English and Arabic transcription on an RTX 5080. Advertise that tested target and validate any additional GPU claims separately. [NVIDIA Blackwell compatibility guide](https://docs.nvidia.com/cuda/archive/12.8.0/blackwell-compatibility-guide/index.html).
- Parakeet commit `1bfbebfaaf493866f49597cd3b7901959d395c60` and ggml commit `e705c5fed490514458bdd2eaddc43bd098fcce9b` both allow binary redistribution under MIT with their full copyright and permission notices. The four upstream ggml patches at the pinned Parakeet commit all passed reverse-application checks against the build checkout, and their touched-file sets matched the local diff. The audio I/O translation unit compiles in David Reid's `dr_wav`; include its MIT No Attribution notice with the other upstream notices. Model weights carry the original model licenses and are distributed separately. [Parakeet license](https://github.com/mudler/parakeet.cpp/blob/1bfbebfaaf493866f49597cd3b7901959d395c60/LICENSE), [ggml license](https://github.com/ggml-org/ggml/blob/e705c5fed490514458bdd2eaddc43bd098fcce9b/LICENSE), [Pinned ggml patches](https://github.com/mudler/parakeet.cpp/tree/1bfbebfaaf493866f49597cd3b7901959d395c60/third_party/ggml-patches), [Audio I/O source](https://github.com/mudler/parakeet.cpp/blob/1bfbebfaaf493866f49597cd3b7901959d395c60/src/audio_io.cpp), [dr_wav license](https://github.com/mudler/parakeet.cpp/blob/1bfbebfaaf493866f49597cd3b7901959d395c60/third_party/dr_wav.h#L9057-L9105), [Upstream model licenses](https://github.com/mudler/parakeet.cpp/blob/master/docs/licenses.md).
- The CUDA 12.8 EULA lists the versioned Windows CUDA runtime and cuBLAS DLLs in Attachment A. The distribution grant has conditions including distribution with a qualifying application that provides material additional functionality, access by that application, and compatible distribution terms. Keep the CUDA redistributables on NVIDIA's download service. The existing build's PE imports include `cudart64_12.dll`, `cublas64_12.dll`, and driver-supplied `nvcuda.dll`. cuBLAS also needs `cublasLt64_12.dll`. A successful MSVC relink of the original 137 CUDA objects with `/VERBOSE:LIB /MAP` showed `cudadevrt.lib` and `cudart_static.lib` searched with zero members from either archive in the map. A second relink excluding both archives produced identical host `.text` and CUDA fatbinary sections to the first relink. The fatbinary sections also matched the original DLL. The two copies of the original `ggml-cuda.dll` in build output and runtime had identical SHA-256 `929c8eef80878967954f4ca4daea085677a94975883b9ac233e72ff27bb20831`. These checks cover host archive selection, and the DLL contains CUDA-generated device code. ## Release checklist

1. Tag the source recipe and record the pinned commits and patch application with `scripts/apply_ggml_patches.sh`. The local build used Ninja, MSVC 19.44.35227, CUDA compiler 12.8.61, and CMake flags `-DCMAKE_BUILD_TYPE=Release -DPARAKEET_BUILD_CLI=ON -DPARAKEET_BUILD_SERVER=OFF -DPARAKEET_SHARED=ON -DPARAKEET_GGML_CUDA=ON -DGGML_NATIVE=OFF -DCMAKE_CUDA_ARCHITECTURES=120 -DGGML_CUDA_FA=OFF -DCMAKE_WINDOWS_EXPORT_ALL_SYMBOLS=ON`. Archive `bin/parakeet.dll`, `bin/ggml.dll`, `bin/ggml-base.dll`, `bin/ggml-cpu.dll`, `bin/ggml-cuda.dll`, build information and the three upstream notices. Describe it as a Simple STT build and keep model files and vendor prerequisites out of the ZIP. [Upstream patch script](https://github.com/mudler/parakeet.cpp/blob/1bfbebfaaf493866f49597cd3b7901959d395c60/scripts/apply_ggml_patches.sh).
2. Document installation of the NVIDIA graphics driver and the Microsoft x64 Visual C++ Redistributable. Get `cudart64_12.dll` from NVIDIA's `cuda_cudart` Windows x64 ZIP and `cublas64_12.dll` and `cublasLt64_12.dll` from its `libcublas` Windows x64 ZIP, verifying each archive against NVIDIA's CUDA 12.8 manifest. For manual integration, the vendor DLLs can sit beside the Parakeet DLLs. Simple STT registers the pinned vendor asset directories with AddDllDirectory. [NVIDIA Windows CUDA installation guide](https://docs.nvidia.com/cuda/archive/12.8.0/cuda-installation-guide-microsoft-windows/index.html), [NVIDIA component manifest](https://developer.download.nvidia.com/compute/cuda/redist/redistrib_12.8.0.json), [Microsoft DLL search flags](https://learn.microsoft.com/en-us/windows/win32/api/libloaderapi/nf-libloaderapi-setdefaultdlldirectories), [Simple STT loader](../../src/infer/parakeet_native.rs).
3. Verify the archive's allowlist, size and SHA-256. Exercise the exact archive with the vendor prerequisites in an isolated and clean Windows setup. Run English and Arabic transcription through `simple-stt-infer`, check that the selected device is the NVIDIA GPU, and check that a missing prerequisite is reported when it is absent. Then verify the public versioned download and its digest before pinning them in the Windows catalog. [Simple STT Windows validation](../testing.md).
4. Point Vulkan and Sherpa entries directly at their upstream releases and pin their specific assets and digests. Parakeet v0.5.0 provides `parakeet-v0.5.0-lib-win-vulkan-x64.zip` (SHA-256 `4527898049ee1566c4b3e12c8a40ddcce154d2fc5c1661ac00a95b64cd6e512c`). Sherpa v1.13.8 lists the Windows x64 shared CPU archive and the Windows x64 CUDA 13/cuDNN 9 archive used by the catalog. [Official Parakeet v0.5.0 assets](https://github.com/mudler/parakeet.cpp/releases/expanded_assets/v0.5.0), [Official Sherpa v1.13.8 assets](https://github.com/k2-fsa/sherpa-onnx/releases/expanded_assets/v1.13.8), [Simple STT download catalog](../../assets/catalog/downloads.json).

# fastText language identification model

`lid.176.ftz` is the original compressed language identification model by Facebook AI Research. Source: [fastText language identification](https://github.com/facebookresearch/fastText/blob/main/docs/language-identification.md); download: https://dl.fbaipublicfiles.com/fasttext/supervised-models/lid.176.ftz. The downloaded model is unmodified. SHA-256: `8f3472cfe8738a7b6099e8e999c3cbfae0dcd15696aac7d7738a8039db603e83`.
